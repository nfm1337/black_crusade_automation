BLACK CRUSADE AUTOMATION v0.7.1

ВАЖНО:
Папка модуля должна называться ТОЧНО:
black-crusade-automation

Правильный путь:
FoundryVTT/Data/modules/black-crusade-automation/module.json

Не должно быть:
Data/modules/black-crusade-automation-v0.7/module.json
Data/modules/black-crusade-automation/black-crusade-automation/module.json

Установка:
1. Закрой Foundry.
2. Распакуй ZIP.
3. Скопируй папку black-crusade-automation в Data/modules/
4. Запусти Foundry.
5. Включи модуль в Manage Modules / Управление модулями.
